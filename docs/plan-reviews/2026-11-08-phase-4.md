# Plan review — phase 4 (training platform) — 2026-11-08

## Summary

One round was run. It found 1 critical, 6 high, 5 medium and 2 low findings, all accepted.
The direction stands: plain PyTorch with local tracking, which are user decisions.

Main changes:
- The equivalence gate is now in three tiers: CPU bit-exact, a deterministic GPU run, and a
  distributional check. The archived runs were non-deterministic, so they cannot be matched
  exactly.
- The registry and the queue come first and run on today's CLI (Track A).
- Run identity is defined, with a `numerics_epoch`.
- Engine and precision enter the comparison signature.
- New flags are written engine-free.
- The data layer has three tiers.
- Durable remote workers.
- Cuts: the legacy modules, the early performance flags and sweeps.
