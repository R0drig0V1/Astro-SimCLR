# Plan review — phase 1 (runnable, tested package) — 2026-11-07

## Summary

The phase file did not exist before this review: the integrator drafted
`docs/phases/01-runnable-package.md` from the legacy code first. The user had asked for the
goal "prove that it can run and leave everything ready to run on a GPU; this Mac has no
GPU".

Three adversarial rounds were run (the maximum).

| Round | Critical | High | Medium | Low | Decision |
|---|---|---|---|---|---|
| 1 | 1 | 7 | 5 | 1 | all accepted after verification |
| 2 | 1 | 4 | 4 | 2 | all accepted after verification |
| 3 | 0 | 3 | 2 | 1 | all accepted after verification |

**Verdict:** the plan is ready to dispatch task 1.1. The round-3 fixes were applied but not
re-attacked, because the round limit was reached. They are local changes: the dry mode,
`--resume`, the prepared data layout and the R3 linear-eval config.

Four research reports informed the plan (web research, 2026-11-07):
- Rubin/LSST data access and ALeRCE papers;
- the science.alerce.online site;
- self-supervised learning on astronomical images;
- GPU options.

Their findings went into the reference numbers, the runbook task, the open questions and
the backlog.
