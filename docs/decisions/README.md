# Architecture decision records

One file per decision, `NNNN-title.md`, with Context / Decision / Consequences.

| # | Decision |
|---|----------|
| [0001](0001-torch-wheels-and-accelerators.md) | Torch wheels and accelerators: PyPI torch by default, conflicting `cpu` / `cu126` extras, torch 2.14 pin, sync discipline |
| [0002](0002-nt-xent-denominator.md) | NT-Xent denominator: the legacy `1 + Σ_neg exp` (close to DCL) by default, the paper's formula behind `nt_xent_legacy_denominator: false` |
| [0003](0003-carrasco2021-preset.md) | The `carrasco2021` preset: ALeRCE's code over the paper text (frozen feature BN, inactive dropout, Glorot fc biases), Adam (0.9, 0.999) with torch's ε placement, the without-features assumption, the NaN approximation, the leaked stamp out of Train only |
| [0004](0004-evaluation-protocol.md) | Evaluation protocol: stored splits (the file is the truth), seed-mean stratified paired bootstrap, exact McNemar, the leaked stamp removed from Train only, CD21 on exactly 5 seeds; amended for split runs and for grouped splits (format version 2: no object, matched within 1.5", in two parts) |
| [0005](0005-paper-model-variants.md) | The paper model's 2.5 architecture variants as orthogonal flags (`paper_arch`, `group_fields`, `context`, `rot90_augment`), faithful defaults listed in the presets, Glorot fans of group layers (the readout as a dense layer), the context normalised like the crop, hand-written p4/p4m layers |
| [0006](0006-class-aware-augmentation.md) | Class-aware training augmentation (plan C5, C6): the difference computed from the science and template through a per-stamp fit, noise scaled to each crop's background sigma then the min-max again, discrete features never jittered, synthetic hot-pixel Bogus from positive-alert Asteroid and Bogus rows (templates mostly empty at the centre; a Bogus keeps its features, an Asteroid takes a batch Bogus donor's), spikes narrower than the measured PSF minimum (1.19 px), per-augmentation step-seeded generators |
| [0007](0007-transient-flux-rescaling.md) | Transient flux rescaling (plan C7): a Gaussian PSF fitted once per Train stamp to the difference's central source, `(k-1)·PSF` added to the difference and `(k-1)·PSF/a` to the science (scaling the whole difference does nothing under the min-max), `magpsf`/`sigmapsf` updated through M1's statistics, `k` log-uniform and floored to keep the stamp an alert, never Bogus |
| [0008](0008-benchmark-metrics-and-object-splits.md) | Phase-3 benchmark metrics and object splits: macro-F1 zero-division rule (classes absent from both left out), macro-F1 reweighted to RJ23's class proportions, the seed-ensemble macro-F1 bootstrap with recounted confusion matrices, groups assigned whole in random order by largest deficit (bound `g` / `(k − 1)g`), stored splits by group id with grouped Validation halves, `candid` as the prediction index, the cross-benchmark rule on the plan's 3 × 3 matrix |
| [0009](0009-rj23-input.md) | The RJ23 input path: the paper's rule for `abs(x) > 1e10` (masked and zeroed) by default, RJ23's code behind `large_values="code"`; the code elsewhere (one 4×4 TF-'same' pooling for the low-res view, iterated 2×2 for the multi-scale, crops at `⌈(n − size) / 2⌉`, NaN skipped then zeroed, empty channels 0) |
| [0010](0010-fp32-precision-policy.md) | The float32 precision policy: `fp32_precision: ieee` (full float32) by default where torch 2.14 would run TF32 convolutions on Ampere+, set at the start of every run (matmuls through `set_float32_matmul_precision`, which Lightning can read), the effective policy recorded in `metrics.json["machine"]` and part of the machine signature, `tf32` a preset deviation |
| [0011](0011-raw-alert-store.md) | Raw alert retrieval (task 3.1): the whole avro through fastavro[snappy] (3 requests per alert, not 5), a minimal strict FITS reader, npz batch shards plus an append-only CSV index, every raw response kept for an offline rebuild, ties decided by the stamp check, ghosts outside the recovery target |
| [0012](0012-raw-alerts-data-in-git.md) | Raw-alert data in git: no cutouts, arrays or raw responses ever; per-row indexes and object-splits files (they list `oid`s of the label set) only after a governance decision; until then the SHA-256 of each frozen version and the rebuild code are committed |
| [0013](0013-rj23-models.md) | RJ23's classifiers (task 3.4): Table 2 as published, 'same' 3×3 convolutions and TF-'same' 2×2 max-pooling (−∞ padding; 63 → 32 → 16 → 8), flatten then the mean over the 8 rotation/flip views, dropout → concat(x, y, z) → BN → FC → ReLU → FC-K, ReLU throughout, Keras defaults (BN momentum 0.99, eps 1e-3, moving variance from the biased batch variance; Glorot-uniform kernels, zero biases); one pre-registered arm, the BN before the concat; Adam eps 1e-7 left to 3.4b |
| [0016](0016-r5-reconstruction.md) | The R5 reconstruction (task 3.5): `JD_MAX` = 2022-12-31, one alert per object drawn with `default_rng([seed, sha256(oid)[:8]])` from the stamped detections sorted by candid, ndet from the stored list, non-63×63 draws dropped; subclasses walked in a seeded permutation to RJ23's counts (caps recorded), SN = Zenodo first then BTS to 3,615; CD21 Asteroid (`ndet == 1`) and Bogus (`ndet < 10`, no Zenodo/BTS oid, ghosts dropped); oid and 1.5" groups across R5 and CD21 with constrained splits (object-splits format 2); everything from snapshots, rebuilt byte for byte |
