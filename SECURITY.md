# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability.
Report it privately through GitHub: **Security** tab → **Report a vulnerability**
(https://github.com/R0drig0V1/astro-simclr/security/advisories/new).

Include what you found, how to reproduce it, the version or commit, and its impact. You will
get a first answer within a week.

## Supported versions

Only the latest release on `main` is supported.
